# Beer Game — Standalone Multiplayer Server

เวอร์ชันนี้รันแยกจาก Claude ทั้งหมด เป็นเว็บแอปสาธารณะที่**ใครก็เข้าเล่นได้โดยไม่ต้องล็อกอิน** รองรับหลายทีมเล่นพร้อมกัน (คนละรหัสทีม) และซิงค์ข้อมูลแบบเรียลไทม์ผ่าน WebSocket ของเซิร์ฟเวอร์คุณเอง

## โครงสร้างไฟล์

```
beer-game-server/
├── package.json
├── server.js          ← เซิร์ฟเวอร์ (Express + WebSocket) คุมกติกาเกมและซิงค์ข้อมูล
└── public/
    ├── index.html
    ├── style.css
    └── app.js          ← โค้ดฝั่งผู้เล่น (เชื่อมต่อ WebSocket, render หน้าจอ)
```

## รันบนเครื่องตัวเอง (ทดสอบก่อน deploy จริง)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
cd beer-game-server
npm install
npm start
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` จะเจอหน้า landing ของเกม ใช้งานเหมือนเวอร์ชันก่อนหน้าทุกอย่าง (กด "ฉันคือ Game Master" → สร้าง/เข้ารหัสทีม → คัดลอกลิงก์แจกผู้เล่น)

## Deploy ให้คนนอกเข้าเล่นได้จริง (ฟรี/ราคาถูก)

เลือกอันใดอันหนึ่ง ทุกอันรองรับ WebSocket และมี HTTPS/WSS ให้อัตโนมัติ:

### Render.com (แนะนำ ง่ายที่สุด)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo (หรือใช้ "Deploy from folder" ถ้ามี)
2. ไปที่ [render.com](https://render.com) → New → Web Service → เชื่อม repo
3. ตั้งค่า: **Build Command** = `npm install`, **Start Command** = `npm start`
4. กด Deploy — จะได้ URL แบบ `https://your-app.onrender.com` ที่ใช้เล่นได้ทันที (แผนฟรีมีจำกัดว่าเซิร์ฟเวอร์จะ sleep ถ้าไม่มีคนใช้นานๆ ตื่นช้าหน่อยตอนเปิดครั้งแรก)

### Railway.app
1. `railway login` แล้ว `railway init` ในโฟลเดอร์นี้
2. `railway up` — ระบบจะ build และ deploy ให้อัตโนมัติ พร้อม URL สาธารณะ

### Fly.io
1. ติดตั้ง `flyctl`, รัน `fly launch` ในโฟลเดอร์นี้ (เลือก Node.js ตอนถาม)
2. `fly deploy`

### VPS ของตัวเอง (DigitalOcean, Linode, ฯลฯ)
1. ติดตั้ง Node.js บนเครื่อง, copy โฟลเดอร์นี้ขึ้นไป
2. รันด้วย [pm2](https://pm2.keymetrics.io/) เพื่อให้ทำงานค้างไว้: `pm2 start server.js --name beer-game`
3. ตั้ง Nginx เป็น reverse proxy พร้อม SSL (เช่นผ่าน Certbot) เพื่อให้มี HTTPS/WSS — จำเป็นถ้าอยากให้ผู้เล่นเข้าจาก `https://` ปกติ

## ข้อควรรู้

- **State อยู่ใน RAM เท่านั้น** — ถ้าเซิร์ฟเวอร์ restart (เช่น deploy ใหม่ หรือแผนฟรี sleep แล้วตื่น) เกมทุกทีมจะรีเซ็ตหมด เหมาะกับการเล่นสดในงานเดียว ไม่ใช่เก็บข้อมูลระยะยาว
- ไม่มีระบบยืนยันตัวตนใดๆ — ใครมีลิงก์ก็เข้าได้ ถ้าไม่อยากให้คนนอกงานสุ่มเข้ามา ให้ตั้งรหัสทีมที่เดายากหน่อย (ไม่ต้องเป็นแค่ 4 ตัวอักษรตามค่าเริ่มต้น พิมพ์เองยาวๆ ก็ได้)
- ปรับจำนวนรอบได้จากหน้า Game Master ก่อนกด "เริ่มเกม" (ค่าเริ่มต้น 40 รอบ)
- ถ้าอยากให้ข้อมูลรอดจาก restart ต้องเพิ่มการเขียนลงไฟล์/ฐานข้อมูลจริง (เช่น SQLite, Redis) — ไฟล์ `server.js` มีคอมเมนต์บอกจุดที่ควรแก้ (ฟังก์ชัน `processRound`, `resetTeam`) ถ้าต้องการต่อยอด

## วิธีเล่น

เหมือนเวอร์ชันก่อนหน้าทุกประการ — ดูคู่มือ "อธิบายผู้เล่นใหม่" ที่เคยได้รับไปก่อนหน้านี้ได้เลย ใช้ได้กับเวอร์ชันนี้เช่นกัน (แค่เปลี่ยนโดเมนลิงก์จาก claude.ai เป็นโดเมนเซิร์ฟเวอร์ที่ deploy ไว้)
